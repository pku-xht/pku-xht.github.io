# 管理后台与 30 天会话

用户要求 `/blog/comment/` 管理所有评论，评论管理和 `/exit/` 编辑页沿用博客 C 风格，并确认一次登录保持 30 天。本轮是此前已发布统一博客的后续改进，用户于 2026-10-26 确认上线，并追加要求友链一起发布。会话迁移、后端和网页均已正式发布，生产核验见末节。

## 实现

评论后台默认“全部评论”，同时提供待审核、已公开和已拒绝视图。文章筛选和昵称/正文搜索都在数据库完整集合上执行，非当前页内过滤；数量受文章和搜索条件影响，状态筛选单独选择要展示的记录。列表按稳定序号倒序，每页最多 100 条，显示文章标题、原文入口、完整时间、父回复标识和状态。审核、拒绝或删除后重新载入当前视图，避免全部视图或回复后代残留旧状态。公开接口仍只返回已批准记录。

评论与编辑界面共用 `services/blog-api/src/admin-style.mjs`，延续纸色背景、蓝色操作、中文衬线标题、细分隔线和紧凑导航。文章仍以完整 Markdown + YAML 编辑，既有 URL、源 SHA 冲突保护及受信构建发布流程保持。

固定账号仍为 `admin`，原管理密码未改变。密码只用于登录交换随机会话；同源 localStorage 保存该会话及到期时间，所有评论/编辑页共用。有效期为创建后 30 天，使用与恢复不延长。D1 仅保存与当前 `ADMIN_TOKEN` 绑定的 HMAC、创建及到期时间。原密码、原会话 token 和草稿不写入 D1；网站存储也不保存原密码或草稿。

主动退出请求撤销当前会话，清除本机缓存，并通知其他页面退出；断网时明确提示服务端撤销未确认。普通离页只清页面内存，重开验证后可继续使用会话。评论页失效清空管理内容；编辑页保留内存中的未保存正文，重新登录后保留原草稿和基准 SHA。迟到的登录、恢复、旧 401 或加载响应不能复活已退出/已替换的状态。
