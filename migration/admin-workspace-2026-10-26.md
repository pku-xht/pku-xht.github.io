# 管理后台与 30 天会话

用户要求 `/blog/comment/` 管理所有评论，评论管理和 `/exit/` 编辑页沿用博客 C 风格，并确认一次登录保持 30 天。本轮是此前已发布统一博客的后续改进，当前仅完成本地实现与下列验证，尚未应用线上会话迁移、部署新 Worker 或推送新页面。

## 实现

评论后台默认“全部评论”，同时提供待审核、已公开和已拒绝视图。文章筛选和昵称/正文搜索都在数据库完整集合上执行，非当前页内过滤；数量受文章和搜索条件影响，状态筛选单独选择要展示的记录。列表按稳定序号倒序，每页最多 100 条，显示文章标题、原文入口、完整时间、父回复标识和状态。审核、拒绝或删除后重新载入当前视图，避免全部视图或回复后代残留旧状态。公开接口仍只返回已批准记录。

评论与编辑界面共用 `services/blog-api/src/admin-style.mjs`，延续纸色背景、蓝色操作、中文衬线标题、细分隔线和紧凑导航。文章仍以完整 Markdown + YAML 编辑，既有 URL、源 SHA 冲突保护及受信构建发布流程保持。

固定账号仍为 `admin`，原管理密码未改变。密码只用于登录交换随机会话；同源 localStorage 保存该会话及到期时间，所有评论/编辑页共用。有效期为创建后 30 天，使用与恢复不延长。D1 仅保存与当前 `ADMIN_TOKEN` 绑定的 HMAC、创建及到期时间。原密码、原会话 token 和草稿不写入 D1；网站存储也不保存原密码或草稿。

主动退出请求撤销当前会话，清除本机缓存，并通知其他页面退出；断网时明确提示服务端撤销未确认。普通离页只清页面内存，重开验证后可继续使用会话。评论页失效清空管理内容；编辑页保留内存中的未保存正文，重新登录后保留原草稿和基准 SHA。迟到的登录、恢复、旧 401 或加载响应不能复活已退出/已替换的状态。

## 本地验证

- 正式构建与校验覆盖 211 篇文章、1 个页面、524 个静态页面；8,961 处正文公式、609 个代码块、40 张图片、5 个附件及 117 条公开评论保持，正文和评论与原快照一致。收尾时另一任务并行维护友链；友链与历史快照的变化由该任务单独负责，不回退或纳入本轮提交。
- 后端、共享会话、管理/编辑客户端、实际 esbuild 与真实 workerd/D1 合计 90 项通过，0 跳过。覆盖绝对到期、恢复/撤销、密码绑定、登录限流、全部/分页/文章/全库搜索、待审隔离、跨页面同步、迟到响应和正文冲突保护。独立复核发现并修复保存后继续编辑的未保存提示问题；源已写回但页面发布失败时，后续编辑也保留离页和重新登录保护。
- Markdown 源隔离 17 项、发布流程 22 项、公开评论源 10 项和阅读页交互 13 项通过。发布流程首次受沙箱阻止创建临时 Git 仓库，放开本地测试权限后 22 项全部通过。Wrangler 4.152.0 的正式打包 dry-run 成功，没有上传或部署。
- Chrome 使用虚构本机密码与仓库外的临时 SQLite 验收：全部视图从 100 条加载到 117 条；评论管理登录后打开文章 `429` 的 `/exit/` 无需再输入密码；刷新编辑页可恢复；评论页退出使另一个编辑页显示重新登录并保留未保存正文。
- 实际操作文章筛选、全库昵称搜索及待审核空状态；另提交一条明确标注的虚构本地留言，观察待审不可见、批准后公开、拒绝后隐藏及后台列表刷新。此后本地测试库为 117 条原公开评论加 1 条已拒绝的虚构留言，线上评论没有变化。
- 桌面评论管理、编辑工作区已检查。390px 同源 iframe 的评论管理、编辑和文章阅读可用宽度及 scrollWidth 均为 375px（另有滚动条），没有页面横向溢出。浏览器 viewport 能力未实际改变 Chrome 宽度，已重置；窄屏结论只来自上述真实 iframe。截图保留在本机忽略目录 `output/admin-workspace-narrow-20261026.png` 等，不作为手机实机或生产验收。真实管理员密码保存和新版本生产会话仍需分别验收。

本地 GitHub 传输仅为内存模拟，没有修改正式文章或线上评论。临时数据库位于仓库之外；真实密码、真实会话及待审核数据没有进入本仓库。
