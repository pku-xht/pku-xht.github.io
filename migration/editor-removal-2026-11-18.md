# 移除在线文章编辑器

2026-11-18，用户收到 `XHT37 Blog Editor` 细粒度 GitHub 访问令牌的到期提醒后，要求完全移除不再使用的在线文章编辑功能。

## 本地改动

- 删除全部 212 个 `/exit/` 页面、共享编辑器资源及其生成逻辑。
- 删除 GitHub 文章读写、候选分支与发布状态接口，以及专用 GitHub Actions 工作流、发布脚本和测试。
- 移除登录响应中的编辑能力标记及共享管理界面的编辑专用样式和文案。
- 保留 Markdown + YAML 正式源、离线构建、评论管理、30 天可撤销管理会话及访问量统计。
- 同步当前说明和维护约定；旧批次的发布与验收记录保留为历史证据。

维护与验证命令以根 `README.md` 为准。重建不会恢复编辑器；独立校验拒绝残留的编辑页面和资源。

## 验证

- 完整构建与独立校验通过：211 篇文章、1 个页面、313 个静态页面；8,961 处公式、609 个代码块、40 张图片和 45 个资源文件通过原有检查。
- Markdown 构建回归 24 项、公开评论回归 10 项、前端回归 33 项通过。
- 后端 68 项全部通过，无跳过；实际运行 esbuild、workerd 和临时 D1，验证旧编辑接口在仍绑定旧 secret 时返回 404，且不发出出站请求。
- 浏览器核验桌面 1440×1000 与窄屏 390×844 的评论管理登录页和列表，未见横向溢出；使用虚构密码和仓库外临时数据库，登录、状态筛选、刷新恢复和退出均通过。
- 本地 HTTP 核验文章与页面的旧 `/exit/` 地址、共享编辑脚本均返回 404，对应阅读页面返回 200。正式文章源和阅读页面没有改动。

## 发布与凭据

当前仅完成本地清理，尚未推送或部署。生产环境仍需发布删减后的 Worker 和静态页面，删除 Worker 的 `GITHUB_EDIT_TOKEN` secret，并撤销 GitHub 上名为 `XHT37 Blog Editor` 的令牌。评论、会话及统计数据库无需重新导入或迁移。
