# Markdown 正式源转换验证

2026-10-24 将已迁入的 211 篇公开文章与 1 个历史“关于我”页面改为独立 Markdown 文件，每篇附 YAML 元数据。范围沿用[全量公开内容验证](validation-public-2026-10-24.md)，隐藏内容与评论继续留在旧站。

## 正式源与快照分工

- 正文维护于 `content/blog/posts/<ID>.md` 与 `content/blog/pages/<ID>.md`；标题、原始发布日期与修改日期、分类、标签、原 URL 和列表摘要保存在各篇 front matter。
- `content/blog/collection.yaml` 登记全部 212 个成员；`resources.yaml` 维护 45 个本地资源的原 URL、路径、大小与 SHA-256。
- 转换后 6,999 个块采用原生 Markdown，133 个复杂块保留 HTML；609 个代码块全部使用 fenced code，1,680 个标题采用 Markdown 标题。原始 TeX、代码字符与有意的行尾空格保留。
- `migration/sources/` 的 JSON／HTML、媒体记录及旧锚点证据保持原样，仅用于历史校验。生成器不读取原快照；一次性导入工具拒绝覆盖已经维护的 Markdown 及清单。
- 原有 C 样式与文章、历史页、分类页 URL 保留。未修改 `blog/blog.css` 与 `blog/blog.js`。
