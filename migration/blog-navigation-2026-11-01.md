# 博客同级导航调整

本轮按用户确认，将「关于我」「标签」「访问量排行」与文章分类放在同一导航层级，查找放在同一行右侧。**已本地生成、验证；未推送或发布。**

导航顺序为：全部文章、关于我、笔记、游记、题解、记录、标签、访问量排行。关于我沿用 `/blog/pages/215/`，标签沿用 `/blog/tags/`；排行榜移到独立的 `/blog/ranking/`。首页不再分别展开这些内容。主导航的标签入口一并移入此行。

查找框在文章列表页实时筛选，使用 `?q=` 保留关键词；从标签云、排行、关于我等无文章列表页面提交时进入首页查找。原有首页 `?tag=` 链接继续可用，标签名称从维护源生成的映射读取。导航允许窄屏换行，查找保持右对齐。

排行 API 和数据不变。新页面生成完整的公开文章标题、链接索引，供客户端解析接口返回的文章 ID；页面只显示真实接口成功返回的前十项，保留加载、失败重试、空列表和未开放状态。没有重新导入访问量，也没有部署后端。
