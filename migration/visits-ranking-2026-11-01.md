# 访问量排行榜 · 2026-11-01

用户要求显示访问量前十。博客主页在标题和全站统计下方新增默认展开的“访问量排行”，显示排名、文章标题和累计访问量，链接直达对应文章；桌面两列，窄屏单列，可折叠。原有搜索、标签筛选及页首访问量继续使用。

累计访问量沿用已继承的逐文基线加新站增量。同量按数值 ID 升序排列；只纳入代码公开注册表及 D1 公开注册表共同登记的文章，排除页面 215 和未注册内容。`GET /v1/visits/ranking` 固定返回至多十个 ID 及计数，不返回私密资料、标题或任意 URL。当前标题和链接从首页已生成的文章集合读取，避免在线改标题后使用过时名称。

排行榜读取不新增访问事件，不写入数据库，不重新导入或修改基线。Visits 关闭时无界面及脚本；未导入基线、数据异常或请求失败时不显示伪排行，可重试。后台、编辑、私密内容和个人主页不纳入此界面。

- 正式构建及 524 页完整性校验通过，211 篇文章、页面 215、8,961 处公式、609 个代码块和 45 项资源保持完整。
- Worker 35 项、前端 21 项、隔离源 23 项测试通过。真实 SQLite 回归覆盖完整累计排序、同量数值 ID 顺序、前十截断、双公开白名单、页面及未知项排除、缺基线拒绝、CORS 和 GET 零写入。
- 前端回归覆盖当前标题和本地链接、未知/重复/非法计数与超过十项的整批拒绝、单飞及重复初始化、失败重试、关闭/无配置零请求和空状态。搜索与标签筛选不改变排行。
- 浏览器使用仅绑定本机的虚构接口验收：桌面两列、390 × 844 窄屏单列，十篇长标题完整保留、无整页横向溢出；折叠、键盘展开、排行文章跳转、搜索独立性及失败后恢复十条均通过。完成后恢复视口。演示次数不进入生产数据库，窄屏不代表手机实机验收。
- Wrangler 4.152.0 本地打包通过；线上原版本、同一 D1、CORS、统计开关及三项密钥绑定名称已只读核对，没有读取或保存密钥值。本批不需要 schema 迁移、数据导入或密钥变更。
