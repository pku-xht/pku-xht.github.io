# 域名与访问量切换准备 · 2026-10-31

本批已完成本地准备，并在 Cloudflare 创建免费域名区域、进入 DNS 核对向导。区域尚未激活，未更换权威名称服务器；代码未推送或部署，未配置正式跳转、采集或导入新的统计基线，也未开启 Visits。此前的公开文章与后台发布状态不受本批影响。

## 已确认目标

- `https://xht37.com/` 与 `https://www.xht37.com/` 跳至 `https://pku-xht.github.io/blog/`，地址栏显示新站域名。
- 旧公开文章和页面跳至新站对应 URL；WordPress 后台、登录和私密页面保留入口，不统一跳转到公开站。
- 全站访问量显示在个人主页 `https://pku-xht.github.io/`，逐文访问量继续使用对应文档计数。
- 统计采用 PV；旧后台的独立全站点击数不能用逐文求和或访客数代替。用户接受短切换窗口的小偏差。
- 用户只有 WordPress 后台和域名管理权限，没有服务器配置权限。用户已确认由 Cloudflare 接管 DNS 并执行逐页跳转，域名注册不迁移，完整保留现有 DNS 记录；接入尚未实施。

## 本地实现

主页页脚增加中英文全站 PV，复用博客的统计客户端。主页省略文档 ID；文档页面同时累加全站和逐文 PV。重试使用同一加载 nonce，切换语言不重新计数；刷新页面计为新 PV。管理页与编辑页不参与计数。

`features.yaml` 是唯一前端开关，生成器据此生成主页配置，并只更新根主页中该配置脚本的内容哈希版本。校验器检查开关、配置和实际页面一致；文章发布器只允许新增的精确生成文件路径，仍不允许写根主页。普通文章编辑不会改变配置或主页引用。

当前前端与 Worker 开关均保持关闭。关闭时不发送 API 请求；缺少有效基线或请求失败时隐藏计数，不显示虚假零值。

独立的旧域名 Worker `xht37-legacy-redirect` 已生成 348 条明确公开路径：212 篇文档、4 个分类、91 个标签、41 个旧域资源；另有 212 个 `p`／`page_id` 查询映射。匹配的 GET/HEAD 默认返回不缓存的 302。`www` 的其余请求保持原请求回源；新增裸域名的其余请求以不缓存的 307 跳到固定旧 `www` 主机，保留方法、路径和查询，避免依赖原服务器的裸域名证书。后台、登录、REST、未匹配和私密路径不会被统一跳到公开新站。编码分隔符、控制字符和双重编码歧义不匹配；关闭 Worker 开发和预览域名。代表分类、标签地址已在旧站实测可达，未穷举所有旧 taxonomy URL。
