# 域名与访问量切换准备 · 2026-10-31

本批已完成本地准备，并在 Cloudflare 创建免费域名区域、进入 DNS 核对向导。区域尚未激活，未更换权威名称服务器；代码未推送或部署，未配置正式跳转、采集或导入新的统计基线，也未开启 Visits。此前的公开文章与后台发布状态不受本批影响。

## 已确认目标

- `https://xht37.com/` 与 `https://www.xht37.com/` 跳至 `https://pku-xht.github.io/blog/`，地址栏显示新站域名。
- 旧公开文章和页面跳至新站对应 URL；WordPress 后台、登录和私密页面保留入口，不统一跳转到公开站。
- 全站访问量显示在个人主页 `https://pku-xht.github.io/`，逐文访问量继续使用对应文档计数。
- 统计采用 PV；旧后台的独立全站点击数不能用逐文求和或访客数代替。用户接受短切换窗口的小偏差。
- 用户只有 WordPress 后台和域名管理权限，没有服务器配置权限。用户已确认由 Cloudflare 接管 DNS 并执行逐页跳转，域名注册不迁移，完整保留现有 DNS 记录；接入尚未实施。

## 本地实现

主页页脚增加中英文全站 PV，复用博客的统计客户端。主页省略文档 ID；文档页面同时累加全站和逐文 PV。重试使用同一加载 nonce，切换语言不重新计数；刷新页面计为新 PV。管理页与编辑页不参与计数。

`features.yaml` 是唯一前端开关，生成器据此生成主页配置，并只更新根主页中该配置脚本的内容哈希版本。校验器检查开关、配置和实际页面一致；文章发布器只允许新增的精确生成文件路径，仍不允许写根主页。普通文章编辑不会改变配置或主页引用。

当前前端与 Worker 开关均保持关闭。关闭时不发送 API 请求；缺少有效基线或请求失败时隐藏计数，不显示虚假零值。

独立的旧域名 Worker 已生成 348 条明确公开路径：212 篇文档、4 个分类、91 个标签、41 个旧域资源；另有 212 个 `p`／`page_id` 查询映射。匹配的 GET/HEAD 默认返回不缓存的 302，其余请求保持原请求回源，后台、登录、REST、未匹配和私密路径不会被统一跳转。编码分隔符、控制字符和双重编码歧义不匹配；关闭 Worker 开发和预览域名。分类与标签的旧路径形式仍待原站实测，不能将 WordPress 常见路径假设写成已验证覆盖。

- 隔离源测试覆盖开启/关闭时的完整生成与校验、错误配置和文档 ID 拒绝；发布测试保留根主页禁止修改的边界。
- 正式源构建与完整性校验通过：211 篇文章、1 页、8,961 处公式、609 个代码块及 45 个资源保持完整。前端 16 项、隔离源 22 项、发布器 23 项测试全部通过；差异空白检查通过。
- Chrome 使用只绑定本机的虚构服务验收。关闭时 API 请求数为 0；开启后一次 GET、一次 POST，PV 从演示值 12,345 增至 12,346。中英文切换与尺寸切换后仍为 12,346。

- 路由生成检查与 Node 离线回归通过，覆盖全部生成映射、后台／REST 与未知请求回源、查询参数隔离、异常编码和 302／301 响应。未在真实 Cloudflare 执行。
- 基线导入 CLI 在 dry-run 和 apply 发请求前核对本地注册集合，缺失或多出 ID 均拒绝；完整虚构基线、缺失、额外及同数量替换回归通过，所在后端测试文件 31 项全部通过。API payload 和批次哈希保持原样，真实 D1 注册表仍由后端独立核对。

正式检查命令以[根 README](../README.md#build-and-check)为准。虚构服务未向生产接口发出请求，演示数值不进入正式配置或基线。

## 待完成的正式切换

1. 按已确认的 Cloudflare 方案核对完整现有记录及证书、原站回源、回退条件。公共 DNS 查询不能代替管理端的完整记录清单。
2. 验证公开路由白名单；后台、登录、私密及未知请求不能因通配跳转丢失，也不能把私密 URL 或内容放入公开映射。
3. 在短窗口取得最新完整逐文 PV 与独立全站 PV，在仓外保存并 dry-run 校验；旧访客数另存，不冒充 PV。
4. 导入完整基线，安排前后端启用与域名跳转，核对精确发布状态。
5. 实测两个旧域名根、代表公开链接、资源、后台登录和私密可见性，再核对全站与逐文增量。

DNS 缓存与旧站仍在处理的请求可能产生小偏差；当前不承诺两个系统严格同时完成事务。
