# 公开博客迁移

本技能用于迁移旧文及已授权公开评论、友链，或维护博客生成器和互动功能；普通主页事实更新不触发本流程。

先读取根 `AGENTS.md`、`migration/README.md` 和根 `README.md` 的博客章节。它们分别保存公开边界、批次状态与正式命令；设计以 `DESIGN.md` 为准。

沿用用户已确认的 C 方案和当前批次，直接完成可独立进行的本地工作。只在新增取舍会实质改变范围、可见性或结果时提问，不重问已确认的设计或隐藏内容安排。

现有文章以每篇 Markdown 及其 YAML 元数据为正式维护源；原始 JSON／HTML 快照仅供迁移校验。源文件、成员清单、导入与构建命令的分工以根 `README.md` 为准，不从旧快照覆盖已经维护的文章。

评论、友链和统计功能沿用当前批次的最新决定，不把旧批次的“评论留旧站”当成永久限制。只读静态资料、可写后端和未来流量切换的入口以根 `README.md` 及其链接的服务说明为准。

按 [迁移与核验流程](references/workflow.md) 操作。检查通过后按项目约定保存独立本地提交，明确区分本地生成、用户验收和实际发布。
