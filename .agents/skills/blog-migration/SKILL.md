# 公开博客迁移

本技能用于迁移旧文、扩展已确认批次，或维护博客生成器与迁入后的文章；普通主页事实更新不触发本流程。

先读取根 `AGENTS.md`、`migration/README.md` 和根 `README.md` 的博客章节。它们分别保存公开边界、批次状态与正式命令；设计以 `DESIGN.md` 为准。

沿用用户已确认的 C 方案和当前批次，直接完成可独立进行的本地工作。只在新增取舍会实质改变范围、可见性或结果时提问，不重问已确认的设计或隐藏内容安排。

按 [迁移与核验流程](references/workflow.md) 操作。检查通过后按项目约定保存独立本地提交，明确区分本地生成、用户验收和实际发布。
