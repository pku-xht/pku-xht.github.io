# 博客区设计候选

2026-10-23 调研。用户已确认首批迁移旧站全部 **29 篇公开笔记**，并要求先提供设计选择。此目录为比较方案的本地原型，尚未选定正式博客设计；现有主页未改动。

打开 [blog-options.html](blog-options.html)，可切换三种布局、目录页与文章页样例、桌面与 390px 手机宽度。沿用项目预览服务时，访问 `/design/blog-options.html`；也可以直接打开该 HTML 文件。所有资源均在本地，无外部字体或脚本请求。

## 调研依据

| 参考 | 当前页面上可核实的组织方式 | 本次采纳的思路 |
|---|---|---|
| [al-folio 博客](https://alshedivat.github.io/al-folio/blog/)及[代码文章](https://alshedivat.github.io/al-folio/blog/2015/code/) | 学术站点中的独立博客入口，文章列表含日期、摘要、标签；正文提供代码展示 | A 借鉴学术主页与博客的统一层级和克制排版，进一步压缩为年份目录 |
| [OI Wiki](https://oi-wiki.org/)及[凸包页面](https://oi-wiki.org/geometry/convex-hull/) | 按算法领域组织的知识目录和搜索入口，技术内容包含公式与代码 | B 借鉴主题导航和从目录进入正文的阅读方式 |
| [PaperMod 示例](https://adityatelange.github.io/hugo-PaperMod/)及[代码示例](https://adityatelange.github.io/hugo-PaperMod/posts/code_syntax/) | 首页按文章展示标题、摘要和日期，文章页有目录、代码和相邻文章入口 | C 借鉴摘要列表与较独立的阅读空间；纸色和衬线标题为本次自拟视觉方向 |
| [旧博客](https://www.xht37.com/) | 四种内容分类，倒序文章摘要及侧栏 | 保留“博客”而非只有资料库的选项，同时减少旧站侧栏中的随机推荐和标签云 |

这些是对已读取原站页面的设计归纳，不代表已安装相应主题，也不要求改用其生成器。原型代码为本项目编写。

## 三种方向

| 方案 | 目录页与文章页 | 适合的用途 | 代价与限制 |
|---|---|---|---|
| A · 学术目录（推荐） | 白底蓝链接，按年份列标题与日期；正文右侧轻量目录 | 延续现有学术主页，快速扫描大量文章 | 首页不展示摘要，随笔氛围较弱；仍可加入分类筛选和搜索 |
| B · 主题知识库 | 左侧主题导航，右侧按领域分组；文章页保留导航与页内目录 | 读者带着算法名称或领域来查资料 | 要维护主题归类；游记等内容需另设入口；窄屏需收起导航 |
| C · 个人博客 | 温暖纸色、衬线标题、逐篇摘要；正文使用单栏与可折叠目录 | 同时容纳技术笔记、游记与个人写作 | 单屏文章较少，211 篇内容需要分页、分类和归档补充查找 |

推荐 A 是基于现有主页的简洁学术风格和后续 211 篇旧文的扫描需求。若主要目标是让读者反复查阅算法资料，B 更合适；若希望博客形成独立的个人写作空间，选 C。搜索、分类、公式和代码支持可用于任一方向，不能把它们误当成某一视觉方案独占的能力。

## 数据与预览边界

- `blog-notes.js` 只包含 29 篇已确认公开笔记的标题、原日期、旧站链接和候选摘要。旧站这些笔记均没有标签；B 的七类主题归类仅为本次设计样例，不是用户确认的正式内容调整。
- 目录标题链接打开旧站原文。文章页样例固定使用《树上背包时间复杂度证明》的节选；补充的三个小节标题只服务于布局比较，不代表已经改写或迁移该文。
- 公式样例使用浏览器 MathML；它仅验证候选布局中的显示空间，不代表已完成全部旧文的 TeX 转换。
- 非公开文章、附件、后台信息均未读取或放入此目录。原型不接入登录、评论或数据服务。
- `blog-options.css`、`blog-options.js` 管理三套候选；选定设计后再实施正式博客，原型不接入主页导航。

## 验证记录

已通过 JavaScript 语法检查，核对 29 个唯一文章 ID、原日期和原链接与本批公开来源一致；页面内 ID 无重复，页内链接目标存在，字体、图标和脚本均为本地资源。

在 Chrome 实际检查三种方案各自的目录页和文章页样例：桌面 6 个状态、390px 手机宽度预览 6 个状态，页面与预览容器均无横向溢出。代码块保留独立横向滚动；手机宽度是容器预览，不是实机验收。

交互验证覆盖：标题搜索“背包”得到 1 篇、数学主题得到 7 篇、该主题中搜索“原根”得到 1 篇、无匹配时显示空结果提示、清空筛选恢复 29 篇。16 处 MathML 公式样例与原文转移代码已在浏览器显示；页面未报告 JavaScript 或资源加载错误。

候选检查不等于已完成 29 篇正文迁移，也不等于用户已选定设计。
