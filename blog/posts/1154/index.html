什么是闵可夫斯基和？

在几何上，给定两个点集 AAA 和 BBB，它们的闵可夫斯基和定义为：
C=A+B=a+b∣a∈A,b∈B C = A + B = { a + b \mid a \in A, b \in B } C=A+B=a+b∣a∈A,b∈B
也就是把 AAA 中的每一个点和 BBB 中的每一个点做向量加法。

【结论】
如果 AAA 和 BBB 都是凸多边形，那么它们的闵可夫斯基和 CCC 也是一个凸多边形。
更绝的是，CCC 的边集，恰好是 AAA 的边集和 BBB 的边集按照极角排序后拼接在一起的结果！

例如：对于点集 P=(0,0),(−3,3),(2,1)P={(0,0),(-3,3),(2,1)}P=(0,0),(−3,3),(2,1) 和 点集 Q=(0,0),(−1,3),(1,4),(2,2)Q={(0,0),(-1,3),(1,4),(2,2)}Q=(0,0),(−1,3),(1,4),(2,2)，

【例题】[JSOI2018] 战争

转化：有交   ⟺  ∃a∈A,b∈B, a+v⃗=b  ⟺  v⃗=b−a∈B+(−A)\iff \exists a\in A, b\in B,\ a+\vec{v}=b \iff \vec{v} = b - a \in B + (-A)⟺∃a∈A,b∈B, a+v=b⟺v=b−a∈B+(−A)。
解法：求出 BBB 与 −A-A−A 的闵可夫斯基和 CCC（凸多边形），问题变为判断点 v⃗\vec{v}v 是否在 CCC 内。复杂度 O((n+m+q)log⁡n)O((n+m+q)\log n)O((n+m+q)logn)。

【例题】[USACO22JAN] Multiple Choice Test P

转化：目标是最大化向量和的模长。模长函数是凸函数，最大值必然在可能和的凸包的顶点上取得。而可能和的集合正是所有组向量集合的闵可夫斯基和。因此，我们只需要计算所有组向量的闵可夫斯基和的凸包，再遍历顶点取最大距离。
解法：对每组向量求凸包，提取边向量（相邻顶点之差），将所有边向量按极角排序，然后从起点开始依次相加，得到闵可夫斯基和凸包的所有顶点，最后计算每个顶点到原点的平方距离，取最大值。复杂度 O(Tlog⁡T)O(T\log T)O(TlogT)（TTT 为总向量数）。

回到 DP：它和优化有什么关系？

在算法竞赛中，我们遇到的通常不是二维平面上的乱斗，而是关于序列的 DP 状态合并。

最经典的场景就是树上背包：

h(k)=max⁡i+j=k(f(i)+g(j)) h(k) = \max_{i+j=k} (f(i) + g(j)) h(k)=i+j=kmax​(f(i)+g(j))

这叫作 (max⁡,+)(\max, +)(max,+) 卷积。通常它的复杂度是 O(∣f∣×∣g∣)O(|f| \times |g|)O(∣f∣×∣g∣) 的。

【结论】
如果 fff 和 ggg 都是上凸函数（即差分单调递减，Δf(i)=f(i+1)−f(i)\Delta f(i) = f(i+1) - f(i)Δf(i)=f(i+1)−f(i) 单调递减），把 fff 和 ggg 的图像看作二维平面上的上凸壳，那么 hhh 的图像恰好就是 fff 和 ggg 的闵可夫斯基和的上边界！

既然凸多边形的闵可夫斯基和只是把边按斜率（极角）排序，而在 1D 函数中，边就是差分，斜率就是差分的值，那么计算 hhh 的差分数组 Δh\Delta hΔh，只需要将 Δf\Delta fΔf 和 Δg\Delta gΔg 这两个单调递减的数组，像归并排序一样合并起来即可！

复杂度发生了质变：从 O(∣f∣×∣g∣)O(|f| \times |g|)O(∣f∣×∣g∣) 降到了 O(∣f∣+∣g∣)O(|f| + |g|)O(∣f∣+∣g∣)。

【例题】[ICPC 2022 Nanjing R] 工厂重现

DP 结构：定义 fu(j)f_u(j)fu​(j) 为以 uuu 为根的子树内选 jjj 个工厂，且所有工厂到 uuu 的加权距离和等辅助信息下的最大贡献。转移是 (max⁡,+)(\max,+)(max,+) 卷积合并各子树。
优化：fuf_ufu​ 是上凸函数，其差分数组单调递减。合并子树等价于对差分数组做闵可夫斯基和（归并）。用平衡树维护差分序列，启发式合并，并支持因连边产生的区间加等差数列的标记。复杂度 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)。

【例题】[APIO 2016] 烟花表演

DP 形式：设 fu(x)f_u(x)fu​(x) 为使 uuu 子树内所有叶子到 uuu 的距离均为 xxx 的最小代价。转移包含 (min⁡,+)(\min,+)(min,+) 卷积：fu(x)=∑vmin⁡yfv(y)+∣wuv+y−x∣f_u(x) = \sum_{v} \min_{y} { f_v(y) + |w_{uv} + y - x| }fu​(x)=∑v​miny​fv​(y)+∣wuv​+y−x∣，并叠加绝对值函数。fuf_ufu​ 均为下凸函数。
与闵可夫斯基和的联系：下凸函数的 (min⁡,+)(\min,+)(min,+) 卷积等价于对其斜率（差分）做闵可夫斯基和。因此转移的本质是合并多个下凸壳的边序列。
实现：利用 Slope Trick，用可并堆（左偏树）维护拐点，以此表示斜率的变化。合并堆即为闵可夫斯基和，插入/删除拐点对应添加绝对值函数等操作。复杂度 O(nlog⁡n)O(n\log n)O(nlogn)。
