ARC093F Dark Horse

题意

  • 有 2n2^n2n 个人，编号为 1∼2n1 \sim 2^n1∼2n，他们要进行一场比赛。
  • 他们首先会排成一排形成一个排列，然后每一轮第 2k−12k-12k−1 和第 2k2k2k 个人对抗，留下胜利者，最终留下的人是冠军。
  • 另有一个大小为 mmm 的编号集合 SSS，编号为 x,y(x<y)x,y(x<y)x,y(x<y) 的对抗结果如下：
    • 若 x=1x = 1x=1 且 y∈Sy \in Sy∈S，则 yyy 胜。
    • 否则 xxx 胜。
  • 求能使得编号为 111 的人成为冠军的排列数。
  • n,m≤16n,m \le 16n,m≤16，1∉S1 \notin S1∈/S，答案对 109+710^9+7109+7 取模。

题解

111 要成为冠军必须打败 nnn 个对手，第 iii 个对手来自大小为 2i−12^{i-1}2i−1 的子树中，也就是 2i−12^{i-1}2i−1 个数中的 min⁡\minmin。

于是问题变成求将 2∼2n2 \sim 2^n2∼2n 这 2n−12^n-12n−1 个数划分成 nnn 个集合，第 iii 个集合中有 2i−12^{i-1}2i−1 个数，每个集合中的 min⁡∉S\min \notin Smin∈/S 的方案数，然后乘上 2n∏i=1n2i−1!2^n \prod_{i=1}^n 2^{i-1}!2n∏i=1n​2i−1!。

考虑容斥，对于一个状态 sss，若第 iii 个集合的 min⁡∈S\min \in Smin∈S，则将 sss 的第 i−1i-1i−1 位设为 111。

最终答案为 ∑s=02n−1(−1)∣s∣f(s)\sum_{s=0}^{2^n-1} (-1)^{|s|} f(s)∑s=02n−1​(−1)∣s∣f(s)，其中 f(s)f(s)f(s) 表示状态为 sss 的方案数，可以通过对 SSS 中的数从大到小 DP 预处理出，总时间复杂度 O(2nnm)\mathcal O(2^nnm)O(2nnm)。

代码

const int N = 16;
int n, m, a[N|1];
modint f[N|1][1<<N|1], ans;

int main() {
	rd(n, m), rda(a, m);
	reverse(a + 1, a + m + 1);
	init(1 << n);
	f[0][0] = 1;
	for (int i = 1; i <= m; i++)
		for (int j = 0; j < (1 << n); j++) {
			f[i][j] += f[i-1][j];
			for (int k = 0; k < n; k++)
				if (!(j >> k & 1))
					f[i][j|1<<k] += f[i-1][j] * binom((1 << n) - a[i] - j, (1 << k) - 1);
		}
	for (int i = 0; i < (1 << n); i++) {
		int s = (1 << n) - 1 - i;
		for (int j = 0; j < n; j++)
			if (!(i >> j & 1)) f[m][i] *= binom(s, 1 << j), s -= 1 << j;
		if (__builtin_popcount(i) & 1) ans -= f[m][i];
		else ans += f[m][i];
	}
	ans *= 1 << n;
	for (int i = 0; i < n; i++) ans *= p[1<<i];
	print(ans);
	return 0;
}
