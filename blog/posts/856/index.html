ARC091F Strange Nim

题意

  • 有 nnn 堆石子，第 iii 堆有 aia_iai​ 个石子和一个整数 kik_iki​。
  • 两个人轮流，每次选择一堆，从中要取出至少一个石子。

代码

inline int SG(int n, int k) {
    int x = n / k, y = n % k;
    return y ? SG(n - (y + x) / (x + 1) * (x + 1), k) : x;
}

int main() {
    int n, w, k, ans = 0;
    rd(n);
    while (n--) rd(w, k), ans ^= SG(w, k);
    prints(ans ? "Takahashi" : "Aoki");
    return 0;
}
