原版
修订版

Page 5

第 7 章的标题由各方面的敌人修改为四面楚歌。

Page 8~9

删除了一部分“杜子德”。

Page 35

涞阳八中修改为衡阳八中，涞阳大视野修改为耒阳大视野。

Page 46

徐明宽的学校由北京师大附中修改为北京师大附属实验中学。

Page 56

在场的现役选手阮行止修改为在场选手阮行止。

Page 61

九名演唱者中，在 WC2018 正式考试中夺得金牌的选手人数由七位修改为六位。

Page 95

将有人对 CCF “连坐”式的惩罚手段的描述“无耻的行径重复多次，话题度就大大的降低，以后就会被认为是正常操作。”修改为“......行径重复多次，话题度就大大的降低，以后就会被认为是正常操作。”

Page 97

而在 CCF 公开的 2017-2018 年度决算报表上，“NOI” 一项的收入是 1518.3 万元，而支出仅为 305.7 万元。也就是说，CCF 举办 NOI 系列赛事的净收入为 1212.6 万元。修改为而根据某位会员泄露出的 2017-2018 年度决算报表，我们可以很容易地计算出 CCF 举办 NOI 系列赛事的净收入达一千余万元。

Page 129
