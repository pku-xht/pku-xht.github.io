ARC092F Two Faced Edges

题意

  • 给定一张 nnn 个点 mmm 条边无重边无自环的有向图。
  • 求每条边反向后整张图的强连通分量个数有没有变化。
  • n≤103n \le 10^3n≤103，m≤2×105m \le 2 \times 10^5m≤2×105。

题解

直接上结论：

对于一条边 u→vu \to vu→v，反向后整张图的强连通分量个数有变化当且仅当恰好满足下列两个条件中的一个：

  1. 忽略这条边后，uuu 能到达 vvv。
  2. 忽略这条边后，vvv 能到达 uuu。

后者是否忽略没区别，直接对于每个点 dfs 出能到达的点即可，时间复杂度 O(nm)\mathcal O(nm)O(nm)。

对于前者，我们实际上要求的就是从 uuu 开始第一条边不走 u→vu \to vu→v 的情况下能否到达 vvv。

考虑对于所有 uuu 相同的边一起计算，设出边分别为 v1…kv_{1\dots k}v1…k​。

首先按照 v1…kv_{1\dots k}v1…k​ 的顺序 dfs 一遍，记录下每个点 kkk 是从哪个 viv_ivi​ 到达的，记作 p(k)p(k)p(k)。

然后按照 vk…1v_{k \dots 1}vk…1​ 的顺序 dfs 一遍，同样记录下每个点 kkk 是从哪个 viv_ivi​ 到达的，记作 q(k)q(k)q(k)。

对于一个 viv_ivi​，若 p(vi)=q(vi)=vip(v_i) = q(v_i) = v_ip(vi​)=q(vi​)=vi​，则说明从 uuu 开始第一条边不走 u→vu \to vu→v 的情况下无法到达 vvv，否则说明可以到达。

总时间复杂度 O(nm)\mathcal O(nm)O(nm)。

代码

const int N = 1e3 + 7, M = 2e5 + 7;
int n, m, u[M], v[M];
bool w[N][N];
int p[N][N], q[N][N];
vi e[N];

void dfs(int x, bool *w) {
    w[x] = 1;
    for (int y : e[x])
        if (!w[y]) dfs(y, w);
}

void dfs(int x, int *p, int z) {
    p[x] = z;
    for (int y : e[x])
        if (!p[y]) dfs(y, p, z);
}

int main() {
    rd(n, m);
    for (int i = 1; i <= m; i++) rd(u[i], v[i]), e[u[i]].pb(v[i]);
    for (int x = 1; x <= n; x++) {
        dfs(x, w[x]);
        p[x][x] = q[x][x] = x;
        for (int y : e[x]) if (!p[x][y]) dfs(y, p[x], y);
        reverse(e[x].begin(), e[x].end());
        for (int y : e[x]) if (!q[x][y]) dfs(y, q[x], y);
    }
    for (int i = 1; i <= m; i++)
        prints((w[v[i]][u[i]] ^ (p[u[i]][v[i]] != q[u[i]][v[i]])) ? "diff" : "same");
    return 0;
}
