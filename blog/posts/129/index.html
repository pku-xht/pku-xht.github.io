二分图

如果一张无向图 (V,E)(V, E)(V,E) 存在点集 A,BA,BA,B，满足 ∣A∣,∣B∣≥1|A|,|B| \ge 1∣A∣,∣B∣≥1，A∩B=∅A \cap B = \varnothingA∩B=∅，A∪B=VA \cup B = VA∪B=V，且对于 x,y∈Ax,y \in Ax,y∈A 或 x,y∈Bx,y \in Bx,y∈B，(x,y)∉E(x,y) \notin E(x,y)∈/E，则称这张无向图为一张二分图，A,BA,BA,B 分别为二分图的左部和右部。

二分图判定

定理

一张无向图是二分图，当且仅当图中无奇环。

染色法

时间复杂度 O(n)\mathcal O(n)O(n)。

const int N = 1e6 + 7;
int n, m, v[N];
vi e[N];

bool dfs(int x, int c) {
    v[x] = c;
    for (int y : e[x]) {
        if (v[y] == c) return 0;
        if (!v[y] && !dfs(y, 3 - c)) return 0;
    }
    return 1;
}

int main() {
    rd(n), rd(m);
    for (int i = 1, x, y; i <= m; i++)
        rd(x), rd(y), e[x].pb(y), e[y].pb(x);
    for (int i = 1; i <= n; i++)
        if (!v[i] && !dfs(i, 1)) return prints("No"), 0;
    prints("Yes");
    return 0;
}
【例题】P1525 关押罪犯

这道题有一种扩展域并查集的解法，在此不赘述。

题意抽象出来的模型就是：

给定一张无向图，边有边权。
找到最小的权值 kkk，使得只保留权值 >k> k>k 的边时，图是一张二分图。

二分答案，二分图染色判定即可。

二分图最大匹配

图的匹配

对于一张无向图 (V,E)(V, E)(V,E)，若存在一个边集 E′E^{\prime}E′，满足 E′⊆EE^{\prime} \subseteq EE′⊆E，且对于任意 p,q∈E′p,q \in E^{\prime}p,q∈E′，p,qp,qp,q 没有公共端点，则称 E′E^{\prime}E′ 为这张无向图的一组匹配。

二分图最大匹配

在二分图中，包含边数最多的一组匹配被称为二分图的最大匹配。

其他相关定义

对于任意一组匹配 SSS，属于 SSS 的边被称为匹配边，不属于 SSS 的边被称为非匹配边。

匹配边的端点被称为匹配点，其他点被称为非匹配点。

如果二分图中存在一条连接两个非匹配点的路径 pathpathpath ，使得非匹配边与匹配边在 pathpathpath 上交替出现，那么称 pathpathpath 是匹配 SSS 的增广路。

增广路的性质

  1. 长度为奇数。
  2. 奇数边是非匹配边，偶数边是匹配边。
  3. 如果把路径上所有边的状态（是否为匹配边）取反，那么得到的新的边集 S′S^{\prime}S′ 仍然是一组匹配，并且匹配的边数增加了 111。

结论

二分图的一组匹配 SSS 是最大匹配，当且仅当图中不存在 SSS 的增广路。

匈牙利算法

主要过程

  1. 初始时设 SSS 为空集，即所有边都是非匹配边。
  2. 寻找增广路 pathpathpath，把 pathpathpath 上所有边的匹配状态取反，得到一个更大的匹配 S′S^{\prime}S′。
  3. 重复第 2 步，直到图中不存在增广路。

寻找增广路

依次尝试给每一个左部点 xxx 寻找一个匹配的右部点 yyy。

yyy 与 xxx 匹配需满足下面两个条件之一：

  1. yyy 是非匹配点。
  2. yyy 已与 x′x^\primex′ 匹配，但从 x′x^\primex′ 出发能找到另一个 y′y^\primey′ 与之匹配。

时间复杂度

O(nm)\mathcal O(nm)O(nm)。

【模板】P3386 【模板】二分图匹配
const int N = 2e3 + 7;
int n, m, t, f[N], ans;
bool v[N];
vi e[N];

bool dfs(int x) {
    for (int y : e[x])
        if (!v[y]) {
            v[y] = 1;
            if (!f[y] || dfs(f[y])) return f[y] = x, 1;
        }
    return 0;
}

int main() {
    rd(n), rd(m), rd(t);
    for (int i = 1, x, y; i <= t; i++) {
        rd(x), rd(y);
        if (x > n || y > m) continue;
        e[x].pb(y + n), e[y+n].pb(x);
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n + m; j++) v[j] = 0;
        ans += dfs(i);
    }
    print(ans);
    return 0;
}

二分图匹配模型的两个要素

  1. 点能分成两个集合，每个集合内部有 000 条边。简称 000 要素。
  2. 每个点只能与 111 条匹配边相连。简称 111 要素。
【例题】U64949 棋盘覆盖

给定一个 nnn 行 nnn 列的棋盘，有 mmm 个格子禁止放置。
求最多能不重叠地往棋盘上放多少块长度为 222 宽度为 111 的骨牌。

  • 111 要素：每个格子只能被一张骨牌覆盖，一张骨牌覆盖 222 个相邻的格子。
    把棋盘上没有被禁止的格子作为点，骨牌作为边（两个相邻的格子对应的点之间连边）。

  • 000 要素：把棋盘黑白相间染色，相同颜色的格子不可能被同一骨牌覆盖。
    那么，若把白色格子作为左部点，黑色格子作为右部点，则刚才建立的无向图是二分图。

使用匈牙利算法求上述二分图的最大匹配，时间复杂度为 O(n2m2)\mathcal O(n^2m^2)O(n2m2)。

【例题】U64965 車的放置

車的攻击范围为同一行或同一列的其他棋子。
给定一个 nnn 行 mmm 列的棋盘，有 ttt 个格子禁止放置。
求最多能放多少个不能互相攻击的車。

  • 111 要素：每行、每列只能放 111 个車。
    把行、列作为点，如果一个格子没有被禁止，则在此格子所在行和列对应的点连边。

  • 000 要素：行节点之间没有边，列节点之间也没有边。
    那么，若把行节点作为左部点，列节点作为右部点，则刚才建立的无向图是二分图。

使用匈牙利算法求上述二分图的最大匹配，时间复杂度为 O((n+m)nm)\mathcal O((n+m)nm)O((n+m)nm)。

特殊的二分图匹配

完备匹配

对于一张二分图 ((A,B),E)((A, B), E)((A,B),E)，设其最大匹配为 E′E^{\prime}E′，若 ∣A∣=∣B∣=∣E′∣|A| = |B| = |E^{\prime}|∣A∣=∣B∣=∣E′∣，则称这张二分图具有完备匹配。

多重匹配

对于一张二分图 ((A,B),E)((A, B), E)((A,B),E)，从 EEE 中选出尽量多的边，使 x∈Ax \in Ax∈A 最多与 lxl_xlx​ 条选出的边相连，y∈By \in By∈B 最多与 ryr_yry​ 条选出的边相连，则称选出的边为二分图的多重匹配。

方法有两个。

一是拆点求解二分图最大匹配，即将每个 x∈Ax \in Ax∈A 拆成 lxl_xlx​ 个点，每个 y∈By \in By∈B 拆成 ryr_yry​ 个点。

二是网络流，见后文。

最优匹配

对于一张二分图，边有边权，所有最大匹配中边权总和最大的，被称为最优匹配。

方法同样有两个。

一是 KM 算法，本文选择不介绍，感兴趣的读者可自行研究。

二是费用流，同样见后文。

二分图最小点覆盖

图的点覆盖

对于一张无向图 (V,E)(V, E)(V,E)，若存在一个点集 V′V^{\prime}V′，满足 V′⊆VV^{\prime} \subseteq VV′⊆V，且对于任意 e∈Ee \in Ee∈E，eee 至少有一个端点属于 V′V^{\prime}V′，则称 V′V^{\prime}V′ 为这张无向图的一组点覆盖。

二分图最小点覆盖

在二分图中，包含点数最少的一组点覆盖被称为二分图的最小点覆盖。

定理

从定义上即可发现，匹配和点覆盖是很相似的。

实际上在二分图中，最小点覆盖包含的点数，等于最大匹配包含的边数。

二分图最小点覆盖模型的一个要素

  1. 每条边有两个端点，二者至少选择一个。简称 222 要素。
【例题】UVA1194 Machine Schedule

有两台机器 A,BA,BA,B，它们分别有 n,mn,mn,m 种模式。
有 kkk 个任务，第 iii 个任务在 A,BA,BA,B 上执行的模式为 ai,bia_i,b_iai​,bi​。
任务可以以任意顺序被执行，但每台机器转换一次模式就要重启一次。
求怎样分配任务并合理安排顺序，能使机器重启次数最少。

  • 222 要素：每个任务要么在 AAA 上以 aia_iai​ 模式执行，要么在机器 BBB 上以 bib_ibi​ 模式执行。
    把 A,BA,BA,B 的 n,mn,mn,m 种模式分别作为 nnn 个左部点和 mmm 个右部点，每个任务作为边连接左部点 aia_iai​ 和右部点 bib_ibi​。

求这张二分图的最小点覆盖，时间复杂度为 O(nm)\mathcal O(nm)O(nm)。

【例题】POJ2226 Muddy Fields

在一块 n×mn \times mn×m 的地面上，有一些格子是泥泞的，有一些格子是干净的。
现在需要用一些宽度为 111 长度任意的木板把泥地盖住，同时不能盖住干净的地面，木板可以重叠。
求最少需要多少块木板。

  • 222 要素：每块泥地要么被横着的木板盖住，要么被竖着的木板盖住。
    横着的木板只能放在同一行若干个连续的泥地上，称这种连续的泥地为行泥泞块；竖着的木板只能放在同一列若干个连续的泥地上，称这种连续的泥地为列泥泞块。
    把行泥泞块作为左部，列泥泞块作为右部点。对于每块泥地，在其对应的行泥泞块和列泥泞块之间连边。

求出这张二分图的最小点覆盖即可。

二分图最大独立集

图的独立集

对于一张无向图 (V,E)(V, E)(V,E)，若存在一个点集 V′V^{\prime}V′，满足 V′⊆VV^{\prime} \subseteq VV′⊆V，且对于任意 p,q∈V′p,q \in V^{\prime}p,q∈V′，(p,q)∉E(p,q) \notin E(p,q)∈/E，则称 V′V^{\prime}V′ 为这张无向图的一组独立集，包含点数最多的独立集被称为图的最大独立集。

图的团

对于一张无向图 (V,E)(V, E)(V,E)，若存在一个点集 V′V^{\prime}V′，满足 V′⊆VV^{\prime} \subseteq VV′⊆V，且对于任意 p,q∈V′p,q \in V^{\prime}p,q∈V′，(p,q)∈E(p,q) \in E(p,q)∈E，则称 V′V^{\prime}V′ 为这张无向图的一组团，包含点数最多的团被称为图的最大团。

定理

无向图 GGG 的最大团，等于补图 G′G^\primeG′ 的最大独立集。

对于一般无向图，最大团、最大独立集是 NPC 问题。

二分图最大独立集

在二分图中，包含点数最多的一组独立集被称为二分图的最大独立集。

定理

对于一张 nnn 个点的二分图，最大独立集大小，等于 n−n-n− 最小点覆盖点数，等于 n−n-n− 最大匹配边数。

【例题】P3355 骑士共存问题

骑士的攻击范围为「日」字对角的其他棋子。
给定一个 nnn 行 nnn 列的棋盘，有 mmm 个格子是障碍。
求最多能放多少个不能互相攻击的骑士。

黑白相间染色棋盘，把黑、白色格子分别作为左、右部点，则「日」字对角的两个点颜色一定不同。

若两个格子是「日」字对角，则在对应的点之间连边。

求上述二分图的最大独立集即可。

注意：本题匈牙利算法无法 AC，正解为网络流，见后文。

【例题】P2423 [HEOI2012]朋友圈

一张无向图有 A,BA,BA,B 两类点，AAA 类点有权值 aaa，BBB 类点有权值 bbb。
若 x,y∈Ax,y \in Ax,y∈A 且 axxor⁡ay mod 2=1a_x \operatorname{xor} a_y \bmod 2 = 1ax​xoray​mod2=1，则 x,yx,yx,y 之间有边。
若 x,y∈Bx,y \in Bx,y∈B 且 bxxor⁡by mod 2=0b_x \operatorname{xor} b_y \bmod 2 = 0bx​xorby​mod2=0 或 count⁡(bxor⁡by) mod 2=1\operatorname{count}(b_x \operatorname{or} b_y) \bmod 2 = 1count(bx​orby​)mod2=1，则 x,yx,yx,y 之间有边，其中 count⁡(x)\operatorname{count}(x)count(x) 表示 xxx 在二进制下 111 的个数。
另外给定 mmm 条边 (x,y)(x,y)(x,y)，保证 x∈Ax \in Ax∈A 且 y∈By \in By∈B。
求这张图的最大团。

观察原图，AAA 中权值奇偶性不同的点之间有边，BBB 中所有奇数权值的点之间有边、所有偶数权值的点之间有边、权值奇偶性不同的点之间一部分有边。

一般图的最大团问题是 NPC 的，然而这张图的补图很特殊。

观察补图，AAA 中奇数权值的点构成完全图、偶数权值的点构成完全图，BBB 中奇数权值的点和偶数权值的点构成二分图。

由于无向图的最大团，等于补图的最大独立集。

因此 AAA 中最多取两个点，可以枚举这两个点 x,yx,yx,y，删除与 xxx 或 yyy 之间无边的 BBB 中的点，然后在 BBB 中剩余的点上求二分图的最大独立集即可。

有向无环图的最小路径点覆盖

给定一张有向无环图，用尽量少的不相交的简单路径覆盖所有点（也就是每个点恰好被覆盖一次），这样的路径集合被称为最小路径点覆盖。

拆点二分图

把每个点拆成编号为 xxx 和 x+nx + nx+n 的两个点。

建立一张新的二分图，1∼n1 \sim n1∼n 是左部点，n+1∼2nn + 1 \sim 2nn+1∼2n 是右部点。

对原图的每条有向边 (x,y)(x,y)(x,y)，在二分图的左部点 xxx 与右部点 y+ny + ny+n 之间连边。

最终得到的二分图成为原图的拆点二分图。

定理

有向无环图的最小路径点覆盖包含的路径条数，等于 n−n-n− 拆点二分图的最大匹配边数。

【模板】P2764 最小路径覆盖问题

有向无环图的最小可重复路径点覆盖

给定一张有向无环图，用尽量少的可相交的简单路径覆盖所有点（也就是每个顶点可以被覆盖多次），这样的路径集合被称为有向无环图的最小可重复路径点覆盖。

方法：对有向图进行传递闭包，转化为最小路径点覆盖即可。

网络流

一个网络 G=(V,E)G = (V,E)G=(V,E) 是一张有向图，图中每条有向边 (x,y)∈E(x,y) \in E(x,y)∈E 都有一个给定的权值 c(x,y)c(x,y)c(x,y)，称为边的容量。特别地，若 (x,y)∉E(x,y) \notin E(x,y)∈/E，则 c(x,y)=0c(x,y) = 0c(x,y)=0。图中还有两个指定的特殊节点 S,T∈V(S≠T)S,T \in V(S \neq T)S,T∈V(S=T)，分别被称为源点和汇点。

  1. 容量限制：f(x,y)≤c(x,y)f(x,y) \leq c(x,y)f(x,y)≤c(x,y)。
  2. 斜对称：f(x,y)=−f(y,x)f(x,y)=-f(y,x)f(x,y)=−f(y,x)。
  3. 流量守恒：任意 x≠S,x≠Tx \neq S,x \neq Tx=S,x=T，∑(u,x)∈Ef(u,x)=∑(x,v)∈Ef(x,v)\sum_{(u,x)\in E} f(u,x) = \sum_{(x,v)\in E} f(x,v)∑(u,x)∈E​f(u,x)=∑(x,v)∈E​f(x,v)。

则 fff 称为网络的流函数。

对于 (x,y)∈E(x,y) \in E(x,y)∈E，f(x,y)f(x,y)f(x,y) 称为边的流量，c(x,y)−f(x,y)c(x,y) - f(x,y)c(x,y)−f(x,y) 称为边的剩余流量。

∑(S,v)∈Ef(S,v)\sum_{(S,v) \in E} f(S,v)∑(S,v)∈E​f(S,v) 称为整个网络的流量。

通俗地讲，我们想象一下自来水厂到你家的水管网是一个复杂的有向图，每一节水管都有一个最大承载流量。
自来水厂不放水，你家就断水了。但是就算自来水厂拼命地往管网里面注水，你家收到的水流量也是上限，毕竟每根水管承载量有限。
你想知道你能够拿到多少水，这就是一种网络流问题。

最大流

对于一个给定的网络，使整个网络的流量最大的合法的流函数被称为网络的最大流，此时的流量被称为网络的最大流量。

简单地讲，就是上面那个问题。

EK 增广路算法

增广路是指从 SSS 到 TTT 的一条路径，流过这条路径，使得当前的流量可以增加。

那么求最大流问题可以转换为不断找增广路的问题，并且当图中不存在增广路时就达到了最大流。

找增广路时，直接暴力从 SSS 到 TTT 广搜即可，从 SSS 开始不断向外广搜，通过剩余流量大于 000 的边，直到找到 TTT 为止。

找到增广路之后，记增广路上的最小剩余流量为 fff，则最大流加上 fff，增广路上的每一条边的剩余流量减去 fff，增广路上的每一条边的反向边的剩余流量加上 fff。

时间复杂度 O(nm2)\mathcal O(nm^2)O(nm2)，实际运用中远远达不到，能够处理 103∼10410^3 \sim 10^4103∼104 规模的网络。

Dinic 算法

残量网络

在任意时刻，网络中所有节点以及剩余容量大于 000 的边构成的子图被称为残量网络。

EK 算法每轮可能会遍历整个残量网络，但只找出一条增广路，就很浪费。

分层图

将图分层，节点深度 dxd_xdx​ 表示 SSS 到 xxx 最少需要经过的边数。

在残量网络中，满足 dy=dx+1d_y = d_x + 1dy​=dx​+1 的边 (x,y)(x,y)(x,y) 构成的子图被称为分层图。

显然，分层图是一张有向无环图。

Dinic 算法

不断重复以下步骤，直到残量网络中 SSS 不能到达 TTT：

  1. 在残量网络上 BFS 求出节点层次，构造分层图。
  2. 在分层图上 DFS 寻找增广路，在回溯时实时更新剩余容量。另外，每个点可以流向多条出边，同时还加入若干剪枝及优化。

时间复杂度 O(n2m)\mathcal O(n^2m)O(n2m)，不加剪枝和优化复杂度是错的，实际运用中远远达不到，能够处理 104∼10510^4 \sim 10^5104∼105 规模的网络。

【模板】P3376 【模板】网络最大流
namespace Dinic {
    const int N = 1e5 + 7, M = 2e6 + 7;
    const ll inf = 1e18;
    int n, S, T, d[N];
    int h[N], hi[N], e[M], t[M], tot;
    ll f[M], mxf;

    inline void add(int x, int y, ll z, bool o = 1) {
        e[++tot] = y, f[tot] = z, t[tot] = h[x], h[x] = tot;
        if (o) add(y, x, 0, 0);
    }

    inline bool bfs() {
        for (int i = 1; i <= n; i++) d[i] = 0;
        queue<int> q;
        q.push(S), d[S] = 1;
        while (q.size()) {
            int x = q.front();
            q.pop();
            for (int i = h[x]; i; i = t[i]) {
                int y = e[i];
                ll z = f[i];
                if (d[y] || !z) continue;
                q.push(y), d[y] = d[x] + 1;
                if (y == T) return 1;
            }
        }
        return 0;
    }

    ll dfs(int x, ll now = inf) {
        if (x == T) return now;
        ll rst = now;
        for (int &i = hi[x]; i; i = t[i]) {
            int y = e[i];
            ll z = f[i];
            if (d[y] != d[x] + 1 || !z) continue;
            ll k = dfs(y, min(z, rst));
            if (!k) d[y] = 0;
            else f[i] -= k, f[i^1] += k, rst -= k;
            if (!rst) break;
        }
        return now - rst;
    }

    inline void main() {
        while (bfs()) {
            for (int i = 1; i <= n; i++) hi[i] = h[i];
            ll now;
            while ((now = dfs(S))) mxf += now;
        }
    }

    inline void init(int _n, int _S, int _T) {
        n = _n, S = _S, T = _T, tot = 1, mxf = 0;
        for (int i = 1; i <= n; i++) h[i] = 0; 
    }
}

最大流解决二分图多重匹配

新建一个源点 SSS 和一个汇点 TTT，从 SSS 向每个左部点 xxx 连一条容量为 lxl_xlx​ 的边，从每个右部点 yyy 向 TTT 连一条容量为 ryr_yry​ 的边，把原二分图的每条边看作从左部点到右部点连的一条容量为 111 的边。

那么，二分图多重匹配边数，就等于网络最大流。

Dinic 算法在由二分图通过上述方法构造出来的网络中时间复杂度为 O(mn)\mathcal O(m \sqrt n)O(mn​)，比匈牙利算法快，实际表现则更快。

最大匹配是完备匹配

把二分图中的非匹配边看作从左部向右部的有向边，匹配边看作从右部向左部的有向边，构成一张新的有向图。

最小割

给定一个网格 G=(V,E)G=(V,E)G=(V,E)，源点为 SSS，汇点为 TTT。

若一个边集被删去后，源点 SSS 和汇点 TTT 不再连通，则称该边集为网络的割。

边的容量之和最小的割称为网络的最小割。

最大流最小割定理

最大流等于最小割。

集合划分模型

有 nnn 个物品和两个集合 S,TS,TS,T。
将一个物品放入 SSS 集合会花费 aia_iai​，放入 TTT 集合会花费 bib_ibi​。
还有若干个形如 u,v,wu,v,wu,v,w 限制条件，表示如果 uuu 和 vvv 同时不在一个集合会花费 www。
每个物品必须且只能属于一个集合，求最小的代价。

我们对于每个集合设置源点 SSS 和汇点 TTT，第 iii 个点由 SSS 连一条容量为 bib_ibi​ 的边、向 TTT 连一条容量为 aia_iai​ 的边。对于限制条件 u,v,wu,v,wu,v,w，我们在 u,vu,vu,v 之间连容量为 www 的双向边。

注意到当 SSS 和 TTT 不相连时，SSS 能到达 iii 代表物品 iii 放入 SSS，iii 能到达 TTT 代表物品 iii 放入 TTT。

当割开 S→iS \to iS→i 的边，意味着 iii 放入 TTT；当割开 i→Ti \to Ti→T 的边，意味着 iii 放入 SSS；当割开 u,vu,vu,v 之间的边，意味着 u,vu,vu,v 不放入同一个集合。

因此最小割就是最小花费。

平面图最小割

边与边只在顶点相交的图被称为平面图。

对于一个平面图，都有其对应的对偶图：

  • 平面图被划分出的每一个区域当作对偶图的一个点；
  • 平面图中的每一条边两边的区域对应的点用边相连，特别地，若两边为同一区域则加一条回边（自环）。

这样构成的图即为原平面图的对偶图。

平面图最小割等于对偶图最短路。

费用流

给定一个网络 G=(V,E)G = (V,E)G=(V,E)，每条边 (x,y)(x,y)(x,y) 除了有容量限制 c(x,y)c(x,y)c(x,y)，还有一个单位费用 w(x,y)w(x,y)w(x,y)。

当边 (x,y)(x,y)(x,y) 的流量为 f(x,y)f(x,y)f(x,y) 时，有花费 f(x,y)×w(x,y)f(x,y) \times w(x,y)f(x,y)×w(x,y)。

该网格中总花费最小的最大流被称为最小费用最大流，总花费最大的最大流被称为最大费用最大流。

Dinic 算法

在 Dinic 算法求解最大流的基础上，把 BFS 改为 SPFA，把 w(x,y)w(x,y)w(x,y) 当作边权，在残量网络上求最短路，即可求出最小费用最大流。注意：一条反向边边权应为其正向边边权的相反数。

注意此算法的时间复杂度为 O(nmf)\mathcal O(nmf)O(nmf)，其中 fff 为最大流，一般不会被卡。

【模板】P3381 【模板】最小费用最大流
namespace Dinic {
    const int N = 1e5 + 7, M = 2e6 + 7;
    const ll inf = 1e18;
    int n, S, T;
    int h[N], hi[N], e[M], t[M], tot;
    ll d[N], f[M], c[M], mxf, ans;
    bool v[N];

    inline void add(int x, int y, ll z, ll w, bool o = 1) {
        e[++tot] = y, f[tot] = z, c[tot] = w, t[tot] = h[x], h[x] = tot;
        if (o) add(y, x, 0, -w, 0);
    }

    inline bool bfs() {
        for (int i = 1; i <= n; i++) d[i] = inf, v[i] = 0;
        queue<int> q;
        q.push(S), d[S] = 0, v[S] = 1;
        while (q.size()) {
            int x = q.front();
            q.pop(), v[x] = 0;
            for (int i = h[x]; i; i = t[i]) {
                int y = e[i];
                ll z = f[i], w = c[i];
                if (d[y] <= d[x] + w || !z) continue;
                d[y] = d[x] + w;
                if (!v[y]) q.push(y), v[y] = 1;
            }
        }
        return d[T] != inf;
    }

    ll dfs(int x, ll now = inf) {
        if (x == T) return now;
        v[x] = 1;
        ll rst = now;
        for (int &i = hi[x]; i; i = t[i]) {
            int y = e[i];
            ll z = f[i], w = c[i];
            if (v[y] || d[y] != d[x] + w || !z) continue;
            ll k = dfs(y, min(z, rst));
            if (!k) d[y] = inf;
            else ans += k * w, f[i] -= k, f[i^1] += k, rst -= k;
            if (!rst) break;
        }
        v[x] = 0;
        return now - rst;
    }

    inline void main() {
        while (bfs()) {
            for (int i = 1; i <= n; i++) hi[i] = h[i];
            ll now;
            while ((now = dfs(S))) mxf += now;
        }
    }

    inline void init(int _n, int _S, int _T) {
        n = _n, S = _S, T = _T, tot = 1, mxf = 0, ans = 0;
        for (int i = 1; i <= n; i++) h[i] = 0; 
    }
}

namespace no_ok_flow {
    const int N = 1e5 + 7;
    int n, S, T;
    ll d[N], s;
    inline void add(int x, int y, ll l, ll r) {
        Dinic::add(x, y, r - l), d[y] += l, d[x] -= l;
    }
    inline bool main() {
        for (int i = 1; i <= n; i++)
            if (d[i] > 0) Dinic::add(S, i, d[i]), s += d[i];
            else if (d[i] < 0) Dinic::add(i, T, -d[i]);
        Dinic::main();
        return Dinic::mxf == s;
    }
    inline void init(int _n) {
        n = _n, s = 0, S = n + 1, T = n + 2;
        Dinic::init(n + 2, S, T);
        for (int i = 1; i <= n; i++) d[i] = 0;
    }
}

const int M = 10207;
int n, m, l[M];

int main() {

有源汇上下界可行流

从 TTT 到 SSS 连一条下界为 000，上界为 +∞+\infty+∞ 的边，把汇流入的流量转移给源流出的流量，转化为无源汇的网络，然后求解无源汇上下界可行流。

有源汇上下界最大流

【模板】LOJ116 有源汇有上下界最大流

两个方法：

  1. 二分答案 ansansans，从 TTT 到 SSS 连一条下界为 ansansans，上界为 +∞+\infty+∞ 的边，转化为无源汇网络。找到最大的 ansansans，使得该无源汇上下界网络有可行流。
  2. 从 TTT 到 SSS 连一条下界为 000，上界为 +∞+\infty+∞ 的边，转化为无源汇网络。按照无源汇上下界可行流的做法求一次无源汇上下界超级源到超级汇的最大流。回到原网络，在上一步的残量网络基础上，求一次 SSS 到 TTT 的最大流。以下代码采用此方法。
namespace yes_max_flow {
    const ll inf = 1e18;
    int n, S, T;
    inline bool main() {
        no_ok_flow::add(T, S, 0, inf);
        if (!no_ok_flow::main()) return 0;
        Dinic::S = S, Dinic::T = T, Dinic::mxf = 0;
        return Dinic::main(), 1;
    }
    inline void init(int _n, int _S, int _T) {
        n = _n, S = _S, T = _T;
        no_ok_flow::init(n);
    }
}

int main() {
    int n, m, S, T;
    rd(n), rd(m), rd(S), rd(T);
    yes_max_flow::init(n, S, T);
    for (int i = 1, x, y, l, r; i <= m; i++)
        rd(x), rd(y), rd(l), rd(r), no_ok_flow::add(x, y, l, r);
    if (!yes_max_flow::main()) return prints("please go home to sleep"), 0;
    print(Dinic::mxf);
    return 0;
}

有源汇上下界最小流

【模板】LOJ117 有源汇有上下界最小流

同样两个方法：

  1. 二分答案 ansansans，从 TTT 到 SSS 连一条下界为 000，上界为 ansansans 的边，转化为无源汇网络。找到最小的 ansansans，使得该无源汇上下界网络有可行流。
  2. 类似有源汇上下界可行流的构图方法，但先不添加 TTT 到 SSS 的边，求一次超级源到超级汇的最大流。然后再添加一条从 TTT 到 SSS 下界为 000，上界为 +∞+\infty+∞ 的边，在残量网络上再求一次超级源到超级汇的最大流，流经 TTT 到 SSS 的边的流量就是最小流的值。该算法的思想是在第一步中尽可能填充循环流，以减小最小流的代价。以下代码采用此方法。
namespace yes_min_flow {
    const ll inf = 1e18;
    int n, S, T;
    inline bool main() {
        no_ok_flow::main();
        no_ok_flow::add(T, S, 0, inf);
        Dinic::main();
        return Dinic::mxf == no_ok_flow::s;
    }
    inline void init(int _n, int _S, int _T) {
        n = _n, S = _S, T = _T;
        no_ok_flow::init(n);
    }
}

int main() {
    int n, m, S, T;
    rd(n), rd(m), rd(S), rd(T);
    yes_min_flow::init(n, S, T);
    for (int i = 1, x, y, l, r; i <= m; i++)
        rd(x), rd(y), rd(l), rd(r), no_ok_flow::add(x, y, l, r);
    if (!yes_min_flow::main()) return prints("please go home to sleep"), 0;
    print(Dinic::f[Dinic::tot]);
    return 0;
}

DAG 的最小边覆盖。

连边：

  1. (S,i,0,+∞)(S,i,0,+\infty)(S,i,0,+∞)。
  2. (i,T,0,+∞)(i,T,0,+\infty)(i,T,0,+∞)。
  3. 对每条斜坡 (i,j)(i,j)(i,j)，连边 (i,j,1,+∞)(i,j,1,+\infty)(i,j,1,+∞)。

【例题】P4553 80人环游世界

有 nnn 个国家，mmm 个人。
第 iii 个国家必须有 viv_ivi​ 个人经过，不能多也不能少。
对于 i,j(i<j)i,j(i < j)i,j(i<j)，i→ji \to ji→j 有一条费用为 ci,jc_{i,j}ci,j​ 的边（若 ci,j=−1c_{i,j}=-1ci,j​=−1 则表示没有边）。

第 iii 个国家拆成两个点（入点 iii 和出点 i+ni+ni+n），建立源 SSS 汇 TTT 附加源 sss

连边：

  1. (S,s,m,m,0)(S,s,m,m,0)(S,s,m,m,0)。
  2. (s,i,0,m,0)(s,i,0,m,0)(s,i,0,m,0)。
  3. (i+n,T,0,m,0)(i+n,T,0,m,0)(i+n,T,0,m,0)。
  4. (i,i+n,vi,vi,0)(i,i+n,v_i,v_i,0)(i,i+n,vi​,vi​,0)。
  5. 若 i,ji,ji,j 两个国家之间有边，连边 (i+n,j,0,m,ci,j)(i+n,j,0,m,c_{i,j})(i+n,j,0,m,ci,j​)。

namespace no_min_cost_flow {
    const int N = 1e5 + 7;

【例题】P3980 [NOI2008]志愿者招募

有一个项目需要 nnn 天完成，第 iii 天至少需要 aia_iai​ 个人。
有 mmm 类志愿者，第 iii 类可以从第 sis_isi​ 天工作到第 tit_iti​ 天，费用为每人 cic_ici​ 元。
求最小费用。

把每一天看作一个点。

连边：

  1. (i,i+1,ai,+∞,0)(i,i+1,a_i,+\infty,0)(i,i+1,ai​,+∞,0)。
  2. (ti+1,si,0,+∞,ci)(t_i +1, s_i, 0, +\infty, c_i)(ti​+1,si​,0,+∞,ci​)。

在这个无源汇网络中，招募一个第 iii 类志愿者，就会产生一个从 sis_isi​ 到 ti+1t_i+1ti​+1 的环流，并且使花费加 cic_ici​。

这与题目的实际意义正好相对应，在这个网络中求无源汇上下界最小费用可行流即可。

最大权闭合子图

若有向图 GGG 的子图 VVV 满足：VVV 中顶点的所有出边均指向 VVV 内部的顶点，则称 VVV 是 GGG 的一个闭合子图。

若 GGG 中的点有点权，则点权和最大的闭合子图称为有向图 GGG 的最大权闭合子图。

构图方法

建立源点 SSS 和汇点 TTT ，源点 SSS 连所有点权为正的点，容量为该点点权；其余点连汇点 TTT，容量为该点点权的相反数，对于原图中的边 (x,y)(x,y)(x,y)，连边 (x,y,+∞)(x,y,+\infty)(x,y,+∞)。

定理

  • 最大权闭合图的点权和等于所有正权点权值和减去最小割。
  • 上述图的最小割包含 SSS 到不在最大权闭合图内的正权节点的边和在最大权闭合图内的负权节点到 TTT 的边。

推论（最大权闭合图方案）

在残量网络中由源点 SSS 能够访问到的点，就构成一个点数最少的最大权闭合子图。

【例题】P2805 [NOI2009]植物大战僵尸

每个植物都携带了一些能源（可以是负数），某些植物可以保护其它植物。
一个植物可以被吃掉，当且仅当所有保护它的植物都被吃掉了。
僵尸要吃掉一些植物，使得获得的能源最大。

把每个植物当做一个顶点，植物携带的能源为顶点的权值。

如果植物 bbb 在植物 aaa 的攻击范围内，连接一条有向边 (a,b)(a,b)(a,b)，表示 aaa 可以保护 bbb。

由于僵尸从右向左进攻，可以认为每个植物都被它右边相邻的植物保护，对于每个植物 aaa（除最左边一列），向其左边的相邻植物 bbb，连接一条有向边 (a,b)(a,b)(a,b)。

此时可能有一些植物是互相保护的，都不能被吃掉，这样的点（和与其相连的边）应该全部删掉，拓扑排序一遍即可。

如果我们将图转置（即所有边转成其反向边），那么可以吃掉的植物应该构成一个闭合子图，而最优解就是最大权闭合子图。
